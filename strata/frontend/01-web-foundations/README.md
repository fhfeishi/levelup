# 原生 Web 基础冲刺

## 任务说明

通过小案例掌握 HTML、CSS、HTTP、JavaScript、现代 JavaScript、DOM、事件、Fetch、异步编程和模块化。

## 学习顺序

1. **当前：[个人资料卡](./01-profile-card/README.md)**  
   浏览器、HTTP、HTML 基础、CSS 基础和开发者工具。
2. 费用计算器  
   JavaScript 变量、数据类型、条件、函数和数组。
3. 歌单数据整理  
   对象、数组方法、解构、展开语法、Map 和 Set。
4. Todo List  
   DOM、表单、事件、状态和 localStorage。
5. API 搜索页  
   HTTP、JSON、Fetch、Promise、async/await 和错误处理。
6. 模块化音乐库  
   import/export、模块边界和阶段综合练习。

一次只展开一个案例。当前案例完成并复盘后，再创建下一个案例。
